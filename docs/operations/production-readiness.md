# Production Readiness Checklist

No production-readiness claim until evidence and approval exist.

- [ ] Hosting provider/region and terms approved
- [ ] Data-protection roles, lawful processing, retention and deletion reviewed
- [ ] Threat model reviewed; material risks dispositioned
- [ ] Authentication, MFA, authorization and separation-of-duties tests passed
- [ ] Encryption and secrets controls verified
- [ ] Dependencies pinned and vulnerability review completed
- [ ] Database migration/rollback tested
- [ ] Backup protection and retention verified
- [ ] Restore witnessed; RPO/RTO measured against agreed targets
- [ ] Monitoring, alerting and incident response tested
- [ ] Payroll and statutory acceptance gates passed
- [ ] Two consecutive parallel payroll reconciliations accepted
- [ ] Integrations reconciled
- [ ] Training, documentation and support accepted
- [ ] Authorized management go-live approval recorded
